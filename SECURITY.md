# Security policy

## Supported versions

Security reports are currently welcome for the latest published release and the current stable source checkpoint.

## Reporting a vulnerability

Please do **not** report exploitable security issues in public GitHub Issues. If GitHub's private vulnerability reporting is enabled for this repository, use the repository's **Security → Advisories → Report a vulnerability** flow. Otherwise, contact the maintainer privately before disclosing details publicly.

Do not include bracelet identifiers, phone serial numbers, personal data, credentials, signing keys, or unredacted diagnostic logs in a report.

This project is an independent, device-specific Android BLE application. Security reports should include a concise description, affected version, impact, and reproducible steps where possible.

No guaranteed response time or formal security support SLA is currently offered.
