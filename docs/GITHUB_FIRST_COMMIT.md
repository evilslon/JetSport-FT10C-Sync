# Публикация обновления JetSport FT-10C Sync на GitHub

Этот проект уже имеет репозиторий `evilslon/JetSport-FT10C-Sync` и существующую Git-историю. **Не выполняйте `git init`, не удаляйте `.git`, не создавайте новый репозиторий и не используйте force-push.**

Для обновления используйте инструкцию [UPDATE_EXISTING_REPOSITORY_WINDOWS.md](UPDATE_EXISTING_REPOSITORY_WINDOWS.md). Она проверяет состояние существующей ветки, сохраняет историю и описывает безопасное применение подготовленного архива.

Перед публичной публикацией обязательно подтвердите владельца авторских прав в `LICENSE`, проверьте сторонние лицензии и просмотрите `git diff`. Не добавляйте `local.properties`, ключи подписи, локальные логи BLE, APK из `build/`, каталоги `build/` и `.gradle/`.

Публикация коммита, тега `v1.0.0` и GitHub Release выполняется только после явного решения владельца репозитория.
