JetSport FT-10C Sync — исходники для обновления существующего GitHub-репозитория

Содержимое архива предназначено для копирования поверх существующего checkout репозитория evilslon/JetSport-FT10C-Sync.
Архив намеренно не содержит каталога .git. Не выполняйте git init и не удаляйте историю.

Перед публикацией:
1. Прочитайте docs/UPDATE_EXISTING_REPOSITORY_WINDOWS.md.
2. Проверьте git status и git diff в существующем локальном репозитории.
3. Подтвердите copyright-строку в LICENSE и сторонние лицензии.
4. Не добавляйте local.properties, ключи подписи, личные BLE-журналы, build/ и .gradle/.
5. Не создавайте commit/tag/push до окончательного просмотра изменений и решения владельца.

Проверка этой версии: assembleDebug — успешно; unit-тесты — 128/128; APK установлен и проверен пользователем на Huawei Nova 10 SE / Android 13 с FT-10C.
